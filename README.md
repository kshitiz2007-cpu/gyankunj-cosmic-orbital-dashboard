# Gyankunj Cosmic Orbital Dashboard

A standalone, mobile-first educational dashboard featuring a cosmic orbital navigation system, cinematic editorial surfaces, and interactive learning modules.

## Planned stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Motion for React
- Hugeicons

## Design direction

Cosmic Orbital Interface · Radial Bento Architecture · Kinetic Editorial Typography · Premium Glassmorphism.
