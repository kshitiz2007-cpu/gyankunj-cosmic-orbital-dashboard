# Gyankunj — Cosmic Orbital Dashboard

A standalone, mobile-first student dashboard concept for Gyankunj Academy.

## Design direction

- Cosmic orbital navigation with eight circular learning nodes
- Central knowledge hub and concentric orbital geometry
- Cinematic midnight palette with restrained glass depth
- Hindi-first editorial feature and daily practice progress
- Hugeicons iconography and Motion-powered interactions
- Responsive orbital composition and floating mobile dock

## Stack

- Next.js 15 App Router
- React 19 + TypeScript
- Tailwind CSS v4
- Motion for React
- Hugeicons React + Core Free Icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current implementation

The first dashboard foundation includes the responsive home composition, orbital learning nodes, search-filtered subject strip, notification popover, destination preview modal, and floating navigation. Dedicated learning routes, authentication, live student data, and Supabase integration are intentionally left for the next integration phase rather than being simulated.
